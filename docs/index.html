Adaptive Agent Runtime

Reliable context for coding-agent teams.

ARC gives Codex-, Claude-, and OpenCode-style workers a versioned project state, provenance-aware memory, immutable task context, and a transactional integration gate. Agents can forget. The project cannot.

The problem

More agents do not automatically create a better team.

Long-running coding sessions fail in boring but expensive ways: stale assumptions, duplicated exploration, lossy handoffs, conflicting edits, and “verification” that accidentally tests the wrong tree.

STALE CONTEXT

Agent B starts from yesterday’s truth.

ARC tags context with a project state version and checks relevant changes again before integration.

LOSSY MEMORY

A summary silently becomes ground truth.

ARC keeps memory derived and rebuildable. The authoritative event log remains the source of truth.

FAKE VERIFICATION

The tests pass — on the unchanged branch.

ARC verifies the immutable candidate commit in a fresh gate worktree before it can reach integration.

Architecture

State first. Memory second. Integration last.

The core design rule is simple: if deleting the memory index would make you lose what actually happened, that information was stored in the wrong plane.

Authoritative state
  • append-only events
  • task DAG + versions
  • leases + budgets
  • candidate / merged commits
→
Context control
  • versioned memory
  • provenance + supersession
  • real code evidence
  • hard token budget
→
Transactional execution
  • isolated worktree
  • real coding-agent CLI
  • candidate commit
  • gate → cherry-pick

Research thesis

Can context control improve reliability without buying the result with more tokens?

ARC is designed to compare transcript handoff, static structured handoff, vector top-k memory, versioned memory, and adaptive context compilation under matched cost and hidden-test evaluation.

Never hand agents history by default. Hand them a versioned, provenance-aware compilation of the current project state and the minimum useful derived memory for their task.
