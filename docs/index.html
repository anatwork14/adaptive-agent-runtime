The Core Failure Mode

More agents do not create a better team without context control.

Long-horizon coding agent sessions degrade rapidly: stale assumptions persist, agents reverse each other's decisions, and lossy memory summaries contaminate the entire swarm.

Core Substrate

Two-Plane Separation

Authoritative State (append-only events, git refs, leases, task DAG) is strictly separated from derived Adaptive Memory (facts, decisions, procedures, vector indexes). Deleting derived memory never alters project truth.

Novelty Boundary

Naive Vector Memory vs ARC

Standard vector top-k memory causes severe update interference, hallucinating obsolete APIs alongside current ones. ARC provides temporal supersession tags and provenance-tracked validity windows.

Transactional CI

Serialized Integration Gate

Isolated worktrees prevent concurrent dirty writes. The single-writer gate enforces tiered checks: G0 Rebase & Staleness, G1 Syntax/Build, G2 Visible Tests, and G3 Risk-Tiered Verification (V0–V3).
