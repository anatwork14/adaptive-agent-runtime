ARCAdaptive Agent Runtime

Reliable context control for coding-agent teams. ARC separates authoritative project truth from lossy memory, compiles bounded task context, isolates agent work in Git worktrees, and integrates only verified candidate commits.

03 // control architecture
Memory can help the mission. It cannot rewrite the truth.
ARC keeps correctness-critical facts in an authoritative event stream and Git state. Adaptive memory is a rebuildable, provenance-aware projection used only to compile useful task context.

    

      
A1
Authoritative state
Events, task DAG, budgets, leases, commit and gate outcomes.

      
A2
Adaptive memory
Decisions, failures, procedures, validity and supersession.

      
A3
Context compiler
Hard token ceiling, code evidence, task/risk-aware packing.

      
A4
Agent worktree
Isolated repository branch; agent produces a candidate commit.

      
A5
Integration gate
Verify the exact candidate tree, then integrate serially.

    

    

      
memory plane
Versioned memory
Every retained memory can carry provenance, validity intervals and supersession state.

      
context control
Bounded packets
Risk changes allocation, not the hard token ceiling. Context includes actual code evidence and hashes.

      
integration
Candidate-first gate
The gate validates the immutable candidate commit in a fresh verification worktree.

      
recovery
Replayable state
Recorded memory materializations are replayed as data instead of regenerating summaries.

    

  


  

    
04 // current status
Research-grade prototype. Explicit boundaries.
ARC is pre-alpha. The control-plane substrate is implemented; provider CLI compatibility, semantic retrieval and repository-scale evaluation remain active work.

    
Implemented
Event sourcing, deterministic replay, versioned memory, bounded context compilation, worktrees, candidate commits, transactional gate, mock adapter.
Experimental
Codex / Claude / OpenCode CLI wrappers, provider execution paths, Docker-backed command sandbox integration.
Research stage
Semantic embedding provider, learned policies, large repository benchmark, iso-cost multi-agent crossover characterization.
