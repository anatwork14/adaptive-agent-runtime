01

Failure surface

Why scaling the number of agents does not automatically scale software engineering reliability.

Problem model

Agents don't just lose tokens. They lose the project.

Long-running software work mutates underneath every agent. Old summaries become stale, transcripts become expensive, vector recall confuses chronology, and parallel workers can act on different versions of reality.

CTX

Context drift

A correct decision at event 481 can become dangerous at event 612. Retrieval without temporal validity can quietly resurrect obsolete project facts.

MEM

Memory echo

A lossy summary gets retrieved, repeated, and reinforced until the team treats an interpretation as authority.

GIT

Integration race

Multiple successful agent branches can still form one broken repository. Reliability has to be enforced at the merged candidate tree.

02

System map

Click any subsystem. ARC separates authoritative truth from lossy derived memory, then compiles only the context an agent needs.

Interactive architecture

A control plane, not a shared chat log.

The central invariant is simple: adaptive memory is never authoritative. Project truth lives in append-only events and git state. Memory can be compressed, superseded, archived, or rebuilt without changing what actually happened.

Operational stack

Reliability engineered into every handoff.

ARC treats context, memory, execution and integration as one control problem. The runtime is intentionally modular so each policy can be benchmarked against static baselines.

ARC / MEM-02active

Versioned adaptive memory

Every memory object carries source-event provenance, validity boundaries and supersession state. Derived memory stays useful without becoming ground truth.

05

Research thesis

ARC is an experimental research runtime. The research question is not whether agents can remember more, but whether context control improves reliability per unit cost.

Core principle

Never hand agents history. Hand them the current project.

Memory may be lossy. Truth may not.
